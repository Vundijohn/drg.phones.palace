# DRG Phones Palace

Website for DRG Phones Palace — Nairobi-based phone retailer.

## How to use

1. Open `index.html` in a browser to preview the site.
2. Add real phone photos into the `images/` folder. Match the filenames
   already referenced in `index.html` (e.g. `images/iphone-11.jpg`), or
   update the filenames inside the `phones` array near the bottom of
   `index.html` to match your own photo names.
3. Edit the `phones` array in `index.html` to update models, storage,
   condition, specs, deposit and weekly payment amounts.
4. Update the Facebook / Instagram / TikTok links in the Contact section
   (currently placeholder `#` links).
5. Deploy for free with GitHub Pages:
   - Push this folder to a GitHub repository.
   - Go to Settings → Pages → set Source to the `main` branch, `/ (root)` folder.
   - Your site will be live at `https://<your-username>.github.io/<repo-name>/`.

## Structure

```
drg-phones-palace/
├── index.html      # entire site (HTML, CSS, JS all in one file)
├── images/          # add your phone photos here
└── README.md
```
